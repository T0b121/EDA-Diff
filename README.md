# EDA-Diff

EDA-Diff is an open-source, Git-oriented tool for visual and semantic comparison
of electronic design files.

The project starts with KiCad support and is designed around format adapters so
additional EDA formats can be added without duplicating the shared comparison,
rendering, and merge logic.
